API

For developers. Use the agent from your own code with a bearer token. Hide this page again in Settings.

Access

Create a personal API key under Account. A key can do at most what you can do, and it can be limited to fewer permissions. Send it in the Authorization header.

{% if api_enabled %}

The shared token from WEB_API_TOKEN also works. It has the permissions of the {{ 'service' }} role.

{% endif %} {{ code("Authorization: Bearer YOUR_API_KEY") }}

Requests are sent as application/json. Only the endpoints your role may use are listed here and in the OpenAPI document. Searches started with a key appear in the shared workspace; searches started with the shared token stay private to it.

Examples

Start a research run

{{ code('curl -X POST ' ~ base_url ~ '/api/v1/research \\\n -H "Authorization: Bearer $API_KEY" \\\n -H "Content-Type: application/json" \\\n -d \'{"goal": "hiring", "name": "Jan Novak", "city": "Brno",\n "employers": ["Acme"], "lawful_purpose": true,\n "options": {"networks": ["linkedin", "web"], "strictness": "balanced"}}\'') }}

{{ code('curl ' ~ base_url ~ '/api/v1/jobs/JOB_ID \\\n -H "Authorization: Bearer $API_KEY"') }}
